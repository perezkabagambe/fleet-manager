# Fleet Manager

A phone-first web app for tracking a small fleet of cars: details, issues, repairs,
maintenance, purchased parts, costs and email reminders.

- **Frontend:** static web app hosted on GitHub Pages (`/web`)
- **Backend:** Google Apps Script running as the app's own Google account (`/backend`)
- **Data:** stored privately in that Google account's Drive, never in this repository

This repository contains code only. No car data, user data or secrets are stored here.

Status: under construction.
